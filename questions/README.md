题面可以有意保留歧义或单位瑕疵，例如“内存占用率超过30MB”。考核允许 AI 请求澄清，也允许采用当前模型支持的合理解释，但必须在结果中明确说明口径；不能静默替换单位或臆造字段。考核要点中的边界说明用于考官判定，不作为当前模型能力的声明。

考官工具的 `list` 与 `ask --question` 已支持递归发现：题号形如 `T1-001`、`A1-001`、`C1-042`，可直接作为 `--question` 的参数。
