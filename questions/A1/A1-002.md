## 任务

查询FC交换机是否配置了IP？

## 可澄清点

- 问「是要值还是要结论」→ 要「是否配置」的存在性结论，不是对 IP 做模糊匹配。
- 问「IP 为空算什么」→ 算未配置。
- 问「只查 FC 交换机吗」→ 是，主体限定 FC 交换机。

## 考核要点

- 「是否配置」是存在性 / 单值结论，不是对 IP 列做模糊匹配（C46/C51）。
- NULL / 空串 / 空白须区分并声明判据；`is_some/is_none` 只适用可过滤维度（C08）。
- 无布尔 NOT，否定须改写为 `!=` / 德摩根（C07/P03b）。
